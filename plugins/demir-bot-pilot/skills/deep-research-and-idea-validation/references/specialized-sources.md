# Specialized research sources

Use only for the actual research question. Reuse `academic-review.md` for question framing, screening, extraction, appraisal, citation and coverage limits. A database name or scientific package is not evidence of access, completeness or operational readiness. This reference adds source-selection details; it does not activate a clinical pack or authorize experiments.

## Biomedical literature

Use PubMed when its subject coverage fits the question. Record the exact query, database, access date, filters, actual retrieved/screened counts and pagination boundary. Inspect Search Details: automatic term mapping, phrase syntax and field tags can change retrieval. Preserve PMID/DOI and publication/version identity, distinguish abstract access from inspected full text, and check linked corrections/retractions when material. Do not infer study methods or outcomes from a title. Database indexing does not establish study quality, clinical suitability or a recommendation for an individual.

Official starting point: [PubMed User Guide](https://pubmed.ncbi.nlm.nih.gov/help/), reviewed 16 October 2026. Recheck relevant syntax for a real search rather than freezing provider behavior here.

## Patent and technical prior-art research

First establish the technical question, relevant jurisdictions, dates and purpose. USPTO Patent Public Search covers patents and patent application publications; its search landing page also distinguishes application-status, ownership and international-search resources. Use the appropriate official resource for each claim. Preserve publication/application/patent identifiers and dates; distinguish related family members from independent inventions and application publications from granted claims. Explain the searched jurisdictions, terms/classifications, date range and inaccessible material. A preliminary search is not exhaustive prior-art clearance, a validity opinion or permission to commercialize. Route an actual legal conclusion to the jurisdiction-specific legal specialist with current facts and authority.

Official starting point: [USPTO search resources](https://www.uspto.gov/patents/search), reviewed 16 October 2026. Do not submit an unpublished invention or private draft to an external provider without authorization for that disclosure.

## Scientific packages and specialist repositories

Select a package only for a named task, dataset and compatible runtime. Inspect its actual documentation, maintained version, input assumptions, licensing, data provenance and reproducibility constraints before proposing an adapter. Reuse the ML/data specialist for pipeline implementation. Reading documentation does not authorize installation, executing downloaded code, dataset acquisition, paid access or sending private data. Report unavailable full text/data explicitly; never bypass access controls or invent citation content.

Deliver a source-grounded answer with locators and uncertainty. Example: a requested public literature comparison can produce a bounded query/screening synthesis; a question asking only what PMID means needs a direct answer, not a search campaign. Real specialized research remains pending a selected question and, where necessary, approved access.
