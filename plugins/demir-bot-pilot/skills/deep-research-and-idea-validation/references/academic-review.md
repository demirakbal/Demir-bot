# Academic literature and paper review

Extend the [research workflow](../SKILL.md#research-with-evidence) for the requested assignment or research decision. Reuse its source, privacy and execution boundaries. This is an on-demand method, not a separate research engine, university RAG service or claim of systematic-review certification.

## Match the protocol to the task

Reuse the research question, supplied papers, rubric, learning objectives, allowed assistance, required source types, citation style and deliverable. Map material rubric requirements to the planned analysis without inventing unseen criteria. If the rubric is unavailable, state the assumption and continue useful scoped work. Do not turn a single-paper explanation into a literature search or a short assignment into a systematic review.

For a multi-source review, establish a compact protocol before screening: question, scope, relevant population/system/task, source/date/language boundaries, inclusion/exclusion rules, planned evidence fields and stopping condition. Choose only dimensions that matter. Record justified changes to scope so later exclusions are not silently tailored to the desired conclusion. Keep the protocol in the conversation unless a saved document is requested. A requested systematic or scoping review needs its specified method and coverage; when these cannot be met, label the result partial or narrative rather than claiming compliance.

## Find and account for evidence

Use existing available source-provider tools under their actual contracts and authentication scope. Follow the main skill's provider routing; read only the selected provider's instructions. Search public bibliographic metadata with scoped queries, not private coursework, unpublished manuscripts or account details. Do not install a provider, bypass access controls, spend or change accounts to complete retrieval. Supplied papers or accessible author/repository versions can support partial work when a database or publisher is unavailable; identify the version used and material access gaps.

For searches actually performed, retain a compact conversational search log: provider/database, query and filters, search date, returned coverage or pagination limit, and useful record locators. Report actual retrieved/screened counts only when tracked; approximate result totals are not screened counts. Do not fabricate a search history for supplied papers or label general web results an exhaustive database search. Stop at the agreed scope/budget or when further retrieval cannot resolve the key uncertainty; disclose unsearched sources and inaccessible pages. No background updates or arbitrary source quotas.

Deduplicate by persistent identifier where available, then title/authors/year and inspected content. Link preprint, conference, journal, correction and supplementary versions rather than counting them as independent corroboration. Do not merge merely similar titles or assume multiple reports use independent samples. Record which version supports the claim; distinguish bibliographic duplicates from related studies using the same dataset.

Apply inclusion/exclusion rules consistently. Keep concise reasons for consequential exclusions, such as wrong task/population, incompatible evidence type or outside the stated period. Separate duplicate removal, scope exclusion, unresolved eligibility and unavailable full text. Inaccessibility is not a methodological flaw and absence from a bounded search is not proof that evidence does not exist. Do not exclude negative results just because they conflict with the preferred idea. Record screening decisions only for material actually inspected; title/abstract screening is not full-text appraisal.

## Read papers and build the evidence table

Use a small table in the response when comparison benefits from it; otherwise use compact notes. Suitable fields are source identifier/version, evidence type and publication status, question, method/data/sample, comparator, reported outcome with locator, limitations, relevance to the rubric and access coverage. Use “not reported” or “not assessed” only according to what was actually read; do not fill gaps by inference. A requested table is not permission to create a persistent spreadsheet or database.

Distinguish primary empirical studies, theoretical work, reviews, commentary, preprints and peer-reviewed versions. A review can orient the field; inspect original studies for decision-critical empirical claims where accessible. Do not cite an original as read when only a review's account was available. Preprint status is a limitation to disclose, not automatic rejection; peer review alone does not establish correctness. Check relevant version/correction/retraction information when needed for the current claim without asserting a comprehensive retraction search from limited metadata.

Inspect the sections, tables, figures and supplements needed to support the claim. An abstract can support a clearly attributed abstract-level summary, not detailed assertions about unexamined methodology. If extraction loses equations, table headings or figure labels, recover the relevant original using an existing permitted document/PDF capability or state the gap. Do not infer inaccessible results from a title, snippet or citation count. Merely citing a repository does not authorize executing its code.

## Appraise methodology and baselines

Select dimensions suited to the study, not a universal scoring checklist:

- For empirical work, examine design, recruitment or data selection, sample size rationale, measurement validity, confounding, missing data, uncertainty and whether causal language is justified. Separate statistical evidence, effect size and practical significance; absence of a detected effect is not proof of equivalence.
- For computational work, examine task and dataset versions, train/validation/test separation, leakage or contamination, baseline suitability, tuning and compute conditions, metric definitions, uncertainty across runs and ablations. Compare like conditions; a larger number on a different dataset or budget does not establish superiority. Missing details limit interpretation rather than justify invented settings.
- For theoretical work, examine assumptions, definitions, scope of the argument and whether the claimed application satisfies them. Reading a proof is not mechanical verification or an experimental reproduction.
- Across studies, identify reported limitations, independently supported concerns and reviewer hypotheses separately. Consider transfer to the target population/system and dependencies between evidence sources. Do not infer quality from venue prestige or citations alone, invent numerical quality scores, or treat checklist completion as a validity guarantee. Use a rubric's required scoring scheme only with explicit criteria, evidence and uncertainty; do not manufacture precision for missing evidence.

Distinguish author-reported results, reproduced results and proposed verification. This workflow authorizes reading and reasoning only within the request; it does not authorize writing or running checks, experiments, benchmarks, model evaluations or code from papers. Recommend an appropriate verification step when useful without executing it.

## Synthesize and support citations

Organize findings around the research question and rubric, showing agreement, disagreement, alternative explanations and evidence gaps. Explain incompatible tasks, samples, metrics or versions instead of averaging their results. Do not perform a meta-analysis or claim pooled effects without the necessary comparable data, justified method and applicable task scope. Distinguish evidence of absence from absence of evidence and conclusions from speculative extensions.

Place source links and precise page/section/table locators near consequential claims. Verify bibliographic fields against inspected metadata; never invent authors, dates, titles, DOIs, page numbers or quotations. Use the exact version actually read and make secondary citation explicit. Preserve units, comparison direction, conditions and limitations when paraphrasing numbers. Follow requested citation style and applicable quotation limits without claiming formatting alone verifies support.

Deliver at the requested depth: answer/synthesis, material supporting evidence, methods/coverage sufficient to understand the result and unresolved access or validity limits. A concise source note may suffice for one paper; do not impose a full report on every request. Persist search logs, protocols, evidence tables or bibliography files only within an authorized deliverable. Preserve academic attribution and assistance restrictions; do not claim the user conducted experiments or read sources that were not inspected.

Illustrative acceptance, not an executed case: an assignment asks for comparison of two supplied papers. One is an accessible preprint; only the second paper's abstract is available. Identify these limits, compare supported claims, leave unavailable methodological fields unresolved and avoid declaring a benchmark winner across incompatible conditions. Do not invent a database search, count a later version as an independent study, run either repository or label the result a comprehensive systematic review.
