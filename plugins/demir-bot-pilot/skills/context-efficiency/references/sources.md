## Existing skills adapted

Adapt practical source externalization, selective retrieval and structured handoffs from [Agent Skills for Context Engineering](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering), MIT license retained in LICENSE.upstream:
- [filesystem-context](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering/blob/main/skills/filesystem-context/SKILL.md): closest fit for targeted reads and external artifacts.
- [context-optimization](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering/blob/main/skills/context-optimization/SKILL.md): filtering, caching distinctions and task-level costs.
- [context-compression](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering/blob/main/skills/context-compression/SKILL.md): structured continuation records.

This is an adaptation, not an unchanged installation or endorsement of all upstream claims. Exclude universal thresholds/savings, hidden cache control, automatic self-modification, scratch durability assumptions and indiscriminate multi-agent partitioning.

## Primary evidence and optional tools

- [The Complexity Trap](https://arxiv.org/abs/2508.21433) and [JetBrains explanation](https://blog.jetbrains.com/research/2025/12/efficient-context-management/): observation masking versus summarization in software agents. Findings are specific to evaluated models/tasks, not a Demir Bot benchmark.
- [Anthropic: code execution with MCP](https://www.anthropic.com/engineering/code-execution-with-mcp): programmatic filtering and on-demand tool discovery; example savings are not universal.
- [Aider repository maps](https://aider.chat/docs/repomap.html): selected symbols and dependency-ranked context for navigation.
- [OpenAI prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching): current model-specific behavior and usage fields.
- [RTK](https://github.com/rtk-ai/rtk) and [savings explanation](https://github.com/rtk-ai/rtk/blob/master/docs/guide/resources/savings-explained.md): output reduction, bytes and token estimates versus total session usage.
- [QMD](https://github.com/tobi/qmd): local document search, indexing and optional semantic/reranking components.

Do not install all tools or reload all pages during ordinary work. Recheck current details for relevant setup decisions.
